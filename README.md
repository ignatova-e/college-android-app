# Устный счёт — Android-приложение на Kotlin

Учебное приложение для тренировки арифметики.

Ссылка для сдачи: https://github.com/ignatova-e/college-android-app

## Возможности

- СТАРТ создаёт пример с двумя целыми операндами от 10 до 99 включительно и случайной операцией `*`, `/`, `-`, `+`. Фон нового примера белый.
- При делении оба операнда двузначные, а частное всегда целое (в том числе 1).
- Во время решения СТАРТ заблокирован; доступны ввод ответа и ПРОВЕРКА.
- После проверки ввод и ПРОВЕРКА блокируются, СТАРТ снова доступен.
- Правильный ответ окрашивает пример в зелёный, неправильный — в красный. Текстовое сообщение также показывает результат и правильный ответ при ошибке.
- На экране отображаются общее число решённых примеров, правильные и неправильные ответы и процент с двумя знаками после точки, например `66.67%`.
- Отрицательные ответы и ноль поддерживаются. Пустой ввод, один минус и числа вне диапазона Int вызывают подсказку: проверка не считается завершённой и статистика не меняется.
- При повороте сохраняются пример, введённый текст, результат, фон, доступность кнопок, ошибка ввода и статистика через `onSaveInstanceState`. Поворот не заблокирован, Activity пересоздаётся обычным образом.
- Экран прокручивается, чтобы элементы были доступны в горизонтальной ориентации и при открытой клавиатуре.

Статистика относится к текущему сеансу: постоянное хранение после закрытия приложения не предусмотрено заданием.

## Запуск

1. Клонируйте репозиторий и откройте его корневую папку в Android Studio.
2. Выберите JDK 17 для Gradle и установите Android SDK Platform 35 через SDK Manager.
3. Дождитесь синхронизации Gradle.
4. Запустите конфигурацию `app` на эмуляторе или устройстве Android 6.0 (API 23) и выше.

Используются Kotlin 2.1.20, Android Gradle Plugin 8.9.2, Gradle Wrapper 8.11.1. Интерфейс построен программно на стандартных Android Views; дополнительные библиотеки интерфейса не нужны.

## Проверки и APK

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

В Windows используйте `gradlew.bat`. Для командной сборки задайте путь к SDK через `ANDROID_HOME` или `sdk.dir` в локальном файле `local.properties` (не добавляется в Git).

APK после сборки: `app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions выполняет тесты, lint и сборку при push и pull request. После успешного запуска APK доступен во вкладке **Actions → Android build → Artifacts → arithmetic-trainer-debug**.

Unit-тесты проверяют 20 000 генераций с фиксированным seed: границы операндов, целочисленное деление, появление всех операций, а также результаты операций, включая отрицательные значения и ноль.

### Ручная проверка на устройстве

1. При запуске: нулевые счётчики, `0.00%`, доступен только СТАРТ.
2. Нажмите СТАРТ: фон белый, СТАРТ недоступен, ввод и ПРОВЕРКА доступны.
3. Введите часть ответа и поверните устройство: пример и текст должны сохраниться.
4. Отправьте правильный ответ: зелёный фон, счётчики 1/1/0, `100.00%`, ввод и ПРОВЕРКА недоступны.
5. Поверните устройство: результат и блокировки сохраняются, счётчики не увеличиваются.
6. Запустите следующий пример и дайте неверный ответ: красный фон, счётчики 2/1/1, `50.00%`.
7. Решите третий пример верно: `66.67%`.
8. Проверьте пустой ввод и один минус: сообщение об ошибке, статистика без изменений; исправленный ответ можно проверить.
9. Проверьте доступность всех элементов в горизонтальной ориентации и при открытой клавиатуре.

## Структура

- `MainActivity.kt` — интерфейс, обработчики, статистика и сохранение состояния.
- `Exercise.kt` — модель примера, вычисление ответа и генератор.
- `ExerciseTest.kt` — тесты арифметики и генератора.
- `.github/workflows/android.yml` — автоматическая проверка и сборка APK.
